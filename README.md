# NBA Career Longevity Predictor

Predicts whether an NBA player will have a career lasting 5 years or more using early-career statistics. The model is a Gradient Boosting Classifier trained on Kaggle NBA players dataset.

## Features

- Games Played (GP)
- Minutes Per Game
- Points Per Game
- Rebounds Per Game
- Assists Per Game
- Steals Per Game
- Blocks Per Game
- Turnovers Per Game
